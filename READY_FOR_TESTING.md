## 🔧 How to Use the PDF Extraction Tool

### Quick Start
```bash
# 1. Place your resume.pdf in the project folder
# 2. Run the extraction script
.venv/bin/python extract_pdf_to_constants.py resume.pdf

# 3. Review the generated constants.py
code constants.py

# 4. Test locally
pkill -f "python.*app.py"
.venv/bin/python app.py &
sleep 3
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Tell me about your projects"}'

# 5. Check logs for resume detection
tail -20 test_server.log | grep "Resume search"
```

### Expected Output
```json
{
  "answer": "Detailed dynamic response about projects...",
  "confidence": 0.9,
  "sources": ["source1", "source2"],
  "used_resume": true  // ← Should be true for project questions
}
```
